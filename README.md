# SENTRY // VERSION VAULT
### Advanced File Version Control System

SENTRY is a cinematic, high-performance version control system built with Python (Flask) and Tailwind CSS. It allows users to track file changes, visualize differences, and restore previous states with a high-end "The Watch" inspired interface.

## 🚀 Features
- **Version Tracking:** Automatic version incrementing on file changes using SHA-256 hashing.
- **Cinematic UI:** Deep Arctic Navy theme with high-contrast Cyan accents.
- **Visual Diffs:** Side-by-side comparison of text-based file versions.
- **Storage:** Efficient file storage using Zlib compression in a SQLite backend.
- **Restore:** Instantly roll back any file to a previous version.
- **Global Archive:** Searchable history of every file action.

## 🛠️ Tech Stack
- **Backend:** Python 3.12, Flask
- **Database:** SQLite (SQLAlchemy ORM)
- **Frontend:** Tailwind CSS, Jinja2 Templates
- **Security:** Flask-Login, Werkzeug Password Hashing
